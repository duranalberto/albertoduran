This gallery is a local rendering bench for the MDX components available to journal authors. It puts callouts, chat messages, information-rich lists, browser and device mockups, progress steps, and every supported ECharts pattern inside a real publication, where theme changes, narrow layouts, static builds, asset optimization, and optional browser enhancement can all be checked together.

---

## Publication display components

These examples exercise the DaisyUI publication wrappers through strict `daisyui` fences. They stay static on purpose, since these components provide editorial structure while application state belongs in dedicated interactive components.

### Section headers

```daisyui
{
  "component": "section-header",
  "id": "fence-authored-display-components",
  "title": "Fence-authored display components",
  "level": 2,
  "link": {
    "href": "#standard-article-charts",
    "label": "View charts",
    "external": false
  }
}
```

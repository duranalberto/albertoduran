This draft is a local chart bench for the MDX ECharts component. It keeps one example of each supported chart pattern in a real journal publication so article layout, build-time SVG render, no-script behavior, external SVG artifacts, and optional browser enhancement can be checked together.

---

## Standard article charts

These are the everyday publication shapes: line, area, vertical bar, and horizontal bar. The first chart also tests the preferred `hydrate` prop and a client-side formatter preset.

  id="dummy-line"
  title="Monthly visitors"
  caption="Line chart rendered as static SVG, then enhanced on load."
  description="Line chart showing monthly visitors from January through June."
  option={lineOption}
  clientOption={lineOption}
  width={760}
  height={420}
  hydrate="load"
  optionClientPreset="currency"

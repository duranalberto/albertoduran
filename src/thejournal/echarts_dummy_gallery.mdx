This draft is a local rendering bench for the MDX components available to journal authors. It puts callouts, chat messages, information-rich lists, browser and device mockups, progress steps, and every supported ECharts pattern inside a real publication, where theme changes, narrow layouts, static builds, asset optimization, and optional browser enhancement can all be checked together.

---

## Publication display components

These examples exercise the reusable DaisyUI wrappers with different slot combinations, colors, alignments, and content densities. They stay static on purpose, since the components provide publication structure and leave application state or interaction to their consumers.

### Callout cards

The five cards cover every semantic variant, default and custom titles, a
custom icon, a fully overridden theme-aware palette, and rich MDX content. The
long error detail and code sample also stress narrow layouts.
